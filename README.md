# Skills Library

Personal Agent Skills, shared between Codex and Posit Assistant via a plain `skills/` folder.

## Use it

**Codex** — symlink this repo's `skills/` folder to `~/.agents/skills` (personal, all projects),
or drop `.agents/skills` in a specific project pointing here.

**Posit Assistant** — same idea: symlink to `~/.agents/skills`, or `.agents/skills` at project level.

## Structure

- `skills/python-standards/` — ruff config, formatting, conventions
- `skills/r-environment/` — rig + renv usage
- `skills/r-conventions/` — safe coding + style; naming rules in `references/naming.md`
